1. File Organizer Beginner

Skills: os, pathlib, loops, conditionals

Write a script that scans your Downloads folder and sorts files into subfolders by extension — images, documents, videos, everything else.

  1. List every file in a folder with pathlib.Path.iterdir().
  2. Map extensions to folder names with a dictionary ({".jpg": "images", ".pdf": "docs"}).
  3. Create missing folders with mkdir(exist_ok=True) and move files with shutil.move().
  4. Stretch: add a --dry-run flag that prints moves without doing them.
from pathlib import Path
import shutil

downloads = Path.home() / "Downloads"
kinds = {".jpg": "images", ".png": "images",
         ".pdf": "docs", ".mp4": "videos"}

for f in downloads.iterdir():
    if f.is_file() and f.suffix in kinds:
        dest = downloads / kinds[f.suffix]
        dest.mkdir(exist_ok=True)
        shutil.move(str(f), dest / f.name)
print("Done! ✨")

2. Weather API Client Intermediate

Skills: requests, JSON, error handling, f-strings

Fetch live weather data from a free API and print a friendly report. Your first program that talks to the internet.

  1. Get a free key from openweathermap.org (or use the no-key wttr.in service).
  2. requests.get(url, params={...}) — always pass a timeout.
  3. Check response.status_code; parse with response.json().
  4. Handle failures gracefully: try/except requests.RequestException.
  5. Stretch: accept the city as a command-line argument via sys.argv.
import requests

city = "Pune"
r = requests.get("https://wttr.in/" + city,
                 params={"format": "j1"}, timeout=10)
data = r.json()
now = data["current_condition"][0]
print(f"{city}: {now['weatherDesc'][0]['value']}, "
      f"{now['temp_C']}°C (feels {now['FeelsLikeC']}°C)")

⚠️ Needs pip install requests on your machine — the in-browser compiler can't reach the network.

3. Web Scraper Intermediate

Skills: requests, BeautifulSoup, lists, CSV output

Scrape headlines from a news site and save them to a CSV file. Respect robots.txt — scrape gently.

  1. Fetch the page HTML with requests.
  2. Parse with BeautifulSoup(html, "html.parser").
  3. Select headlines with soup.select("h2 a") (inspect the page first!).
  4. Write title + link rows with the csv module.
  5. Stretch: scrape 3 pages and de-duplicate with a set.
import csv, requests
from bs4 import BeautifulSoup

html = requests.get("https://example.com/news", timeout=10).text
soup = BeautifulSoup(html, "html.parser")

rows = [(a.get_text(strip=True), a["href"])
        for a in soup.select("h2 a") if a.get("href")]

with open("headlines.csv", "w", newline="") as f:
    csv.writer(f).writerows([("title", "link"), *rows])
print(f"Saved {len(rows)} headlines.")

⚠️ Needs pip install beautifulsoup4 — and always check a site's terms before scraping.

4. CSV Data Analyzer Advanced

Skills: csv, collections.Counter, statistics, comprehensions

Analyze a real dataset (e.g. your exercise attempts exported as CSV): top categories, averages, trends.

  1. Read rows with csv.DictReader — dictionaries beat index juggling.
  2. Count categories with collections.Counter.
  3. Compute averages with statistics.mean; group with dict comprehensions.
  4. Print a clean text report with f-strings and max(..., key=...) highlights.
  5. Stretch: draw a bar chart with matplotlib.
import csv
from collections import Counter
from statistics import mean

with open("scores.csv") as f:
    rows = list(csv.DictReader(f))

by_topic = {}
for r in rows:
    by_topic.setdefault(r["topic"], []).append(float(r["score"]))

for topic, scores in sorted(by_topic.items()):
    print(f"{topic:12} avg {mean(scores):5.1f}  "
          f"n={len(scores)}")
top = Counter(r["topic"] for r in rows).most_common(1)[0]
print(f"\nMost practiced: {top[0]} ({top[1]} attempts)")
